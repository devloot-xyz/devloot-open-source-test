# Bounty submission checklist

Use this checklist when opening a PR for a bounty.

## Links
- GitHub issue URL: [paste the issue URL]
- GitHub PR URL: [paste the PR URL]

## Changed files
List each changed file and explain how it addresses the linked issue.

## Verification
Record each test command and its result. If tests do not apply, explain why.

## Reviewer handoff
Summarize what changed, what the reviewer should verify, and any remaining concern.
