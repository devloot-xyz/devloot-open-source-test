# Bounty PR review checklist

## Acceptance criteria and diff evidence
For each issue criterion, link the relevant changed file or diff section and record whether it is satisfied.

## Tests
List automated and manual checks reviewed. If evidence is absent, state what is missing and why.

## Risks and follow-up
Describe regression or security risks, affected areas, and any follow-up needed before payout.

## Decision
Record approve, request changes, or dispute, together with the concrete reason and reviewer name.
